# 商店文案草稿 · Kilocean 千浩翻译

## 简短描述
YouTube 中文字幕跟译与网页翻译。自备 DeepSeek / Kimi Key，无登录、无会员墙，权限极小。

## 详细描述
Kilocean 千浩翻译支持 YouTube 原生 CC 字幕跟译：先开启 YouTube 字幕（CC），再点「翻译字幕」。默认只看中文译文；切到「双语」可对照原生字幕，「原文」只显示原生字幕。保持 CC 开启，扩展仅视觉隐藏字幕；停止后恢复。切视频后需再次点击，不做听音转写。

字幕译文显示在播放器内，随播放器进入全屏。字幕请求失败会提示并保留上一条有效译文；识别为中文的字幕不再请求翻译。

普通网页继续提供渐进式整页翻译、划词翻译，支持阅读 arXiv HTML 等论文页；不提供专门论文模式或 PDF 原位翻译。网页默认双语，与 YouTube 分别记住显示模式。可保存翻译网页 HTML 或打印成 PDF。

使用自己的 DeepSeek / Kimi API Key（BYOK），支持简体中文、繁体中文、英语、日语、韩语。无需登录，无会员墙；API 费用由服务商收取。Key 仅存本机，待翻译文本直达所选服务商 API，开发者不接收 Key 或内容。

点击弹窗主按钮、Alt+A 或右键「翻译此页」均按当前页面启动翻译；选中文字按 Alt+T 可划词翻译。只在用户手势后注入，使用 activeTab、scripting、storage、contextMenus 和翻译 API 主机权限，不持续读取所有网站。
